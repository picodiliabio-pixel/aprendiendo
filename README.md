# Brújula Emocional Escolar

Página web estática para realizar un tamizaje orientativo de señales de depresión y ansiedad en estudiantes de grado sexto a once.

## Alcance

- No emite diagnósticos clínicos.
- Procesa las respuestas en el navegador; no envía datos a servidores.
- Debe usarse con consentimiento informado y acompañamiento de orientación escolar, familia o profesionales de salud mental.
- Si aparece riesgo de autolesión, se debe activar la ruta institucional y los servicios de emergencia.

## Cómo ejecutar

Abre `index.html` directamente en el navegador o levanta un servidor local:

```bash
python3 -m http.server 4173
```

Luego visita `http://127.0.0.1:4173/`.
